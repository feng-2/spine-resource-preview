# Product screenshots

- `preview-en.jpg`: the web viewer with official Spine 4.2 examples imported.
- `vscode-preview-en.jpg`: the actual VS Code extension running in a local code-server 4.106.3 host (VS Code 1.106.3), captured on October 10, 2026. It shows native Resources and Animations TreeViews beside the editor Webview, with Spineboy playing `run`. This is an uncomposited 1280 × 720 browser screenshot, not a desktop VS Code environment certification.

Both images use the English interface and official Spine example artwork © Esoteric Software. The artwork's original license is retained in `fixtures/official/4.2/LICENSE` and included in website and VSIX builds.

The canonical screenshots live in this directory. The extension build synchronizes `vscode-preview-en.jpg` to `apps/vscode/assets/preview.jpg`; the website imports the same source and includes an image copy for its downloadable extension README.
